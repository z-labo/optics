transmission_matrix 계산 설명서#

학부생을 위한 입력 광장 추정부터 모드 전달행렬 해석까지

2026년 9월 15일 코드 사본 기준

이 설명서는 transmission_matrix 폴더의 네 실행 파일과 tm_utils.py가 실제로 수행하는 계산을 처음부터 설명한다. 복소수와 행렬 곱을 배우는 학부생이 각 계산의 입력, 수식, 구현 순서, 출력의 의미를 연결해서 읽을 수 있도록 구성했다. 실험 데이터를 새로 계산한 결과 보고서는 아니다. 수치 예제는 따로 표시한 학습용 예제이며, 실측 성능을 뜻하지 않는다.

핵심 결과는 입력 복소 광장의 푸리에 계수를 출력 복소 광장의 푸리에 계수로 보내는 정적 전달행렬이다. 이후 카탈로그의 H 성분 모드 사전을 이용해 이 행렬을 모드 좌표로 표현한다. 모드 행렬은 측정에서 바로 얻는 행렬이 아니라, 입력 모델·출력 보정·회귀·좌표 변환·특잇값 절단을 거친 결과다.

설명 범위에서 MMF_simTM_PIM_fast.py와 MMFEHHEfields_fast.py의 내부 알고리즘은 제외했다. 이 파일들이 제공하는 카탈로그 정보와 전기장 값을 이후 코드에서 어떻게 정규화하고 사용하는지는 설명한다. 프로젝트 파일을 수정하거나 전체 계산을 재실행하지 않고, 읽어 둔 코드 사본으로 작성했다.

1 전체 계산과 읽는 순서#

1.1 네 실행 파일의 역할#

|순서|실행 파일|계산의 목적|대표 산출물| |1|prepare_input.py|입력 카메라의 초점 강도로 공통 pupil 위상을 추정|pupil_model.npz| |2|prepare_outputs.py|출력 위치 이동과 공통 위상 변동을 보정|outputs.npy와 metadata.npz| |3|build_dataset_tm.py|정적 TM 학습과 H 모드 좌표 변환|T_static 및 T_mode 배열| |4|plot_dataset_tm.py|모드 행렬의 제곱계수를 블록 평균하여 표시|비교 그림과 통계 JSON|

계산 흐름은 다음과 같다. SLM 위상와 입력 강도 → 초점 위치 및 포화 검사 → pupil 추정 → primary와 twin 입력 후보 → 출력 reference 정렬 및 위상 보정 → 복소 선형 회귀 → 정적 TM → 모드 사전과 카메라 모델을 통한 좌표 변환 → 제곱계수 그림이다. tm_utils.py는 이 흐름에서 공통으로 쓰이는 실제 수치 계산을 담고 있다.

입력 추정과 출력 전처리는 서로 다른 문제다. 입력 추정은 강도만으로 알 수 없는 입력 위상을 모델로 추정한다. 출력 전처리는 이미 복소수로 복원되어 저장된 Eout 배열을 읽어서 프레임 사이의 기준을 맞춘다. 이 네 파일은 원시 출력 간섭무늬에서 처음으로 복소 광장을 복원하는 프로그램이 아니다.

1.2 계산의 시작점과 끝점#

시작점에는 이미 저장된 SLM 위상, 입력 진폭 배열, 출력 복소 광장 배열, crop 및 위치 보정 CSV가 있다. 결과의 끝점은 카메라에서 관측되는 H 입력/H 출력 관계다. 절대 광파워, 두 편광을 모두 포함하는 완전한 벡터 TM, 독립적인 target 예측 성능을 이 실행만으로 얻는 것은 아니다.

읽는 순서는 2장의 기초 기호, 3장의 데이터 규약, 4~6장의 입력 모델, 7장의 출력 보정, 8~9장의 정적 TM, 10~12장의 모드 변환, 13~16장의 해석과 사용법을 권한다. 선형대수가 익숙하면 2장을 빠르게 읽고 각 행렬의 차원 표를 먼저 확인해도 된다.

2 필요한 수학과 광학의 기초#

2.1 강도와 복소 광장은 다르다#

단색 빛의 빠른 시간 진동을 생략하면, 한 위치의 빛을 진폭과 위상을 가진 복소수로 나타낼 수 있다. 아래에서 i는 허수 단위, A는 음이 아닌 진폭, φ는 라디안 위상이다. 이 문서의 강도는 보정 상수를 생략한 상대 단위다.

\[ E(x,y)=A(x,y)e^{i\phi(x,y)},\qquad I(x,y)=|E(x,y)|^2=A(x,y)^2. \]

카메라가 강도 I만 알려 주면 A=√I는 구할 수 있지만 φ는 정해지지 않는다. 예를 들어 1, −1, i는 모두 강도가 1이다. 따라서 입력 강도 배열의 제곱근에 임의의 0 위상을 붙여서 참 입력 광장이라고 할 수 없다. prepare_input은 회절과 공통 pupil이라는 모델을 추가해서 이 부족한 정보를 추정한다.

두 광장을 더하면 위상에 따라 간섭한다. E₁=1, E₂=1이면 합의 강도는 4이고, E₂=−1이면 0이다. 이것이 강도 자체에 선형 전달행렬을 맞추지 않고 복소 광장에 선형 모델을 맞추는 이유다.

2.2 벡터와 행렬의 방향#

512×512 복소 이미지는 262144개 원소의 벡터로 펼칠 수 있다. 이 코드는 C 순서로 펼치므로 x가 먼저 변하고 그다음 y가 변한다. 이미지 인덱스는 [y,x], 위치 벡터는 [x,y]인 경우가 많다. 두 순서를 혼동하면 이동 방향과 위상 부호가 바뀐다.

수학에서 한 관측의 입력과 출력을 열벡터 f와 y로 쓰면 아래와 같다. 저장 배열은 관측을 행으로 쌓기 때문에 NumPy 식은 두 번째 관계를 사용한다.

\[ y=T f,\qquad \widehat Y=F T^{\mathsf T}. \]

F의 한 행은 한 입력이며 Y의 같은 행은 대응 출력이다. T의 행은 출력 좌표, 열은 입력 좌표다. 위의 전치 기호 T와 전달행렬 이름 T를 구분하자. 행벡터 표현으로 바꿀 때는 단순 전치만 필요하며, 복소켤레를 추가하면 다른 연산이 된다.

복소켤레 전치는 H로 쓴다. 원소를 복소켤레로 바꾸고 행과 열을 교환하는 연산이다. 내적, 최소제곱, 정규직교 판정에서는 이 연산이 필요하다.

\[ a^{\mathsf H}b=\sum_j a_j^*b_j,\qquad \|a\|_2^2=\sum_j|a_j|^2,\qquad \|T\|_F^2=\sum_{j,k}|T_{jk}|^2. \]

np.vdot(a,b)는 첫 인수를 켤레로 만드는 내적이다. Frobenius 노름은 행렬 원소의 제곱크기를 모두 더한 뒤 제곱근을 취한다. 행렬이 물리적으로 정규화된 직교 좌표를 사용하지 않으면 이 노름을 곧바로 총 광파워로 해석하면 안 된다.

2.3 푸리에 변환과 에너지 보존#

푸리에 변환은 이미지를 공간 주파수 성분으로 표현한다. 빠르게 변하는 무늬는 높은 주파수, 넓고 완만한 무늬는 낮은 주파수를 많이 포함한다. N×N 배열에서 norm=’ortho’인 2차원 DFT는 다음 정규화를 쓴다.

\[ \widetilde E[k_y,k_x]=\frac1N\sum_{y=0}^{N-1}\sum_{x=0}^{N-1}E[y,x]\exp\!\left[-\frac{2\pi i}{N}(k_y y+k_x x)\right]. \]
\[ \sum_{x,y}|E[y,x]|^2=\sum_{k_x,k_y}|\widetilde E[k_y,k_x]|^2. \]

두 번째 식이 Parseval 관계다. 2차원 전체 원소 수가 N²이므로 정규화 계수는 1/√(N²)=1/N이다. 일부 주파수만 남기면 보존되는 것은 그 주파수 안의 에너지이며, 버린 성분의 에너지는 사라진다.

fftshift는 저주파의 중심을 배열 중앙으로 옮기는 순서 변경이다. ifftshift는 중심에 배치한 공간 배열을 FFT 입력 순서로 바꿀 때 쓴다. 공간 배열에 ifftshift를 적용하는지 여부도 선형 위상에 영향을 준다. 입력 특징 FFT와 출력 모드 생성 FFT는 이 처리가 같지 않으므로 각각 코드의 순서를 따른다. 기본 정의는 NumPy FFT 공식 문서를 참고할 수 있다 [참고 1].

2.4 보간과 최소제곱#

보간은 격자 사이의 값을 주변 격자값으로 추정하는 계산이다. 네 모서리 값 f₀₀, f₁₀, f₀₁, f₁₁과 소수 위치 α,β∈[0,1]이 있을 때 bilinear 보간은 다음과 같다.

\[ f(\alpha,\beta)=(1-\alpha)(1-\beta)f_{00}+\alpha(1-\beta)f_{10}+(1-\alpha)\beta f_{01}+\alpha\beta f_{11}. \]

가중치의 합은 1이다. 복소 광장을 보간하면 실수부와 허수부에 같은 가중치를 적용한다. 반면 강도를 보간하면 이미 제곱한 값에 가중치를 적용한다. 일반적으로 |ΣwE|²와 Σw|E|²는 다르다. 예를 들어 E₁=1, E₂=−1을 절반씩 보간하면 전자는 0, 후자는 1이다. 입력 카메라와 출력 카메라 모델을 이해하는 핵심 구분이다.

최소제곱은 관측값과 예측값의 차이를 제곱해서 모두 더한 값을 작게 만드는 방법이다. 미지수가 선형이면 행렬 방정식으로 풀고, pupil 위상처럼 지수함수 안에 들어가면 반복 최적화로 푼다. 이 프로젝트는 두 방식을 모두 사용한다.

4 입력 초점 추출과 포화 검사#

4.1 SLM 위상에서 scan 좌표 얻기#

read_metadata는 각 SLM 위상을 풀린 선형 ramp로 취급한다. 높이 Nᵧ=1024, 너비 Nₓ=1272인 raster에서 중간 행과 중간 열의 양 끝 차이로 기울기를 구한다. 긴 거리로 나눠서 float32의 국소 차분 오차를 줄인다.

\[ g_x=\frac{\phi[N_y/2,N_x-1]-\phi[N_y/2,0]}{N_x-1},\quad g_y=\frac{\phi[N_y-1,N_x/2]-\phi[0,N_x/2]}{N_y-1}. \]
\[ q_x=\frac{N_xg_x}{2\pi},\quad q_y=\frac{N_yg_y}{2\pi},\quad \phi[y,x]\simeq\phi[0,0]+g_xx+g_yy. \]

qₓ=1은 SLM 너비에 걸쳐 대략 2π만큼 위상이 증가한다는 뜻이다. 음의 q는 반대 방향 기울기다. np.angle로 접힌 위상 배열에 이 끝점 차분을 그대로 적용하면 주파수를 잘못 읽을 수 있다. 뒤의 InputOpticsModel.ramp는 간격 64로 위상을 샘플링해 선형 모델의 RMS 잔차가 10⁻³ rad 이하인지 검사한다.

4.2 raw 위치를 512 이미지 위치로 바꾸기#

crop의 하한을 c₀, 상한을 c₁이라 한다. 상한은 Python slice처럼 포함하지 않는다. 원본 crop의 첫 픽셀 중심과 마지막 픽셀 중심을 저장 이미지의 0과 511에 맞추므로 길이에는 한 픽셀을 뺀 값이 들어간다.

\[ s_{xy}=\frac{511}{c_1-c_0-1},\qquad p_{512}=(p_{\rm raw}-c_0)\odot s_{xy}. \]

⊙는 성분별 곱이다. calidata.csv의 축 순서는 보정 당시 [shifty,shiftx] 규약을 사용하므로, 코드에서 열 순서를 바꾸고 전치한 뒤 resize 비율을 곱한다. 그 결과를 B와 b라고 하면 대략적인 초점 위치는 qB+b이다. CSV를 직접 해석할 때 이 축 교환을 생략하지 않는다.

4.3 초점 ROI와 배경#

build_dataset는 Ein의 진폭을 제곱해 강도를 복원한다. 예측 위치 근처 ±7픽셀, 즉 최대 15×15 영역에서 가장 밝은 픽셀을 찾는다. 전체 이미지의 최대값을 쓰지 않는 이유는 고정된 0차 회절광을 scan 초점으로 오인하지 않기 위해서다.

밝은 픽셀 주위에 25×25 ROI를 잡는다. 이미지 바깥으로 나가면 ROI 원점을 안쪽으로 이동시킨다. ROI 가장자리 3픽셀 두께의 중앙값을 배경 Bᵢ로 추정하고, 음수를 0으로 자른 신호 Dᵢ=max(Iᵢ−Bᵢ,0)를 계산한다. 중앙값은 일부 밝은 이상치에 평균보다 덜 민감하다.

초점의 무게중심은 최대 픽셀에서 반경 7 안의 배경 제거 신호로 구한다. x,y는 이미지 전체 좌표다.

\[ \bar x_i=\frac{\sum_{j\in\mathcal D_7}x_jD_{ij}}{\max(\sum_{j\in\mathcal D_7}D_{ij},10^{-30})},\qquad \bar y_i=\frac{\sum_{j\in\mathcal D_7}y_jD_{ij}}{\max(\sum_{j\in\mathcal D_7}D_{ij},10^{-30})}. \]

강도가 249.5 이상인 저장 ROI 픽셀과 한 번 팽창한 주변 픽셀은 초기 마스크에서 뺀다. 나머지도 무게중심 반경 12 안으로 제한한다. binary_dilation은 포화된 부분 주변의 오염 가능성까지 제외하는 형태학적 연산이다.

4.4 위치 보정 행렬의 반복 적합#

각 scan의 설계 행은 [qx,qy,1]이다. 이를 쌓은 행렬 X와 측정 중심 C에 대해 3×2 affine 행렬 A를 최소제곱으로 구한다. 마지막 행이 위치 절편이다.

\[ A=\arg\min_A\|XA-C\|_F^2,\qquad X_i=[q_{xi},q_{yi},1]. \]

처음에는 피크−배경이 35보다 크고 0차 위치에서 28픽셀보다 먼 초점을 사용한다. 네 번 반복하면서 위치 오차가 max(0.8, 유효점 오차 중앙값×4)보다 작은 점으로 다시 맞춘다. 최종 valid는 위치 오차 1픽셀 미만, 0차 위치에서 35픽셀 초과 등의 조건을 만족한 scan이다. 정해진 횟수의 이상치 억제 회귀이며, RANSAC이나 확률적인 신뢰구간 계산은 아니다.

valid=False는 pupil 추정에 신뢰하기 어려운 입력이라는 뜻이다. 현재 정적 TM 회귀에서는 이런 일반 scan도 모두 포함한다. valid가 TM 학습 제외 목록이라고 해석하면 실제 실행과 달라진다.

4.5 원본 포화가 resize 이후에 숨어드는 문제#

raw_sample_geometry는 저장 ROI 한 픽셀이 raw 이미지의 어느 네 픽셀에서 왔는지 역산한다. 역좌표 p_raw=p₅₁₂⊙(c₁−c₀−1)/511+c₀의 정수부와 소수부를 구해 네 모서리 및 bilinear 가중치를 만든다.

raw 네 이웃 중 값이 255 이상인 픽셀이 있고 그 가중치가 10⁻⁶보다 크면, 저장 ROI 픽셀을 오염된 것으로 표시한다. 예를 들어 원본 포화값 255와 어두운 값이 섞이면 저장 값은 249.5보다 낮아질 수 있다. 따라서 저장 이미지 임계값만으로는 포화를 모두 찾지 못한다.

audit는 모든 scan의 ROI에서 원본 intensity 보간과 저장 intensity를 비교한다. 별도로 고르게 선택한 최대 24프레임에 대해 raw crop → zoom(order=1) → 제곱근을 재현한다. 마지막 비교는 바깥 마스크 경계가 불확실한 15픽셀을 피한 내부 원에서 수행한다. processing_audit.json의 오차는 이 전처리 재현성 진단이며, pupil 위상 추정 오차가 아니다.

fit에서는 기존 마스크와 raw 오염 마스크를 결합한다. 포화 코어의 실제 강도를 복구한 것이 아니라 그 픽셀을 적합에서 제외한 것이다. 제외된 중심의 예측은 주변 데이터와 pupil 모델에 의존한다.

5 공통 pupil 위상의 추정#

5.1 pupil과 초점의 관계#

pupil은 렌즈가 통과시키는 개구 안의 복소 광장이다. 코드에서는 진폭은 원형 개구 안에서 일정하다고 두고 위상만 낮은 차수 함수로 바꾼다. 좌표 u,v는 SLM 픽셀 단위이며, 반경은 아래 고정 광학값에서 계산한다.

\[ R_p=\frac{f\,NA_{\rm obj}}{d_{\rm SLM}}=\frac{4000\times0.42}{12.5}=134.4\ \text{SLM pixels}. \]
\[ P(u,v)=\mathbf1_{u^2+v^2\le R_p^2}\exp\!\left(i\sum_{k=1}^{12}a_kZ_k(u/R_p,v/R_p)\right),\qquad h=\mathcal F_{\rm ortho}\{P\}. \]

h는 점확산함수의 복소 진폭이다. 입력 ramp가 달라지면 주로 초점 위치와 공통 위상이 달라지고, 같은 pupil에서 나온 초점 모양이 이동한다고 가정한다. 입력 모니터 광학계와 실제 입사 광학계의 수차를 서로 분리해 식별하는 모델은 아니다.

5.2 Zernike 다항식#

Zernike 함수는 단위원 위에서 정의된 다항식 기저다. 원형 렌즈 수차를 적은 계수로 표현하기 편하다. n은 방사 차수, m은 각 방향 차수이며 |m|≤n, n−|m|가 짝수인 조합을 쓴다.

\[ R_n^{|m|}(\rho)=\sum_{k=0}^{(n-|m|)/2}\frac{(-1)^k(n-k)!}{k!\,[(n+|m|)/2-k]!\,[(n-|m|)/2-k]!}\rho^{n-2k}. \]
\[\begin{split} Z_n^m(\rho,\theta)=R_n^{|m|}(\rho)\begin{cases}\sqrt{n+1},&m=0,\\ \sqrt{2(n+1)}\cos(m\theta),&m>0,\\ \sqrt{2(n+1)}\sin(|m|\theta),&m<0.\end{cases} \end{split}\]

코드는 n=2,3,4를 사용한다. n=2에서 m=−2,0,2의 3개, n=3에서 4개, n=4에서 5개로 총 12개다. 예를 들어 n=2,m=0은 √3(2ρ²−1)이고 초점 이탈과 관련된 위상 모양이다. m=±2는 방향에 따라 달라지는 비점수차 형태를 표현한다.

n=0의 piston과 n=1의 tip/tilt는 기저에서 빠져 있다. 강도만으로 공통 piston을 측정할 수 없고, 초점 이동은 affine 기하 보정에서 다루기 때문이다. 기저 이름은 저장된 zernike_names를 확인한다. 광학 문헌의 단일 번호 표와 임의로 같은 번호라고 가정하지 않는다.

5.3 계산 격자와 전방 모델#

적합할 때 pupil은 2 SLM 픽셀 간격으로 샘플링한다. 대칭성을 위해 홀수 크기를 사용하며 기본값에서는 145×145다. 이를 2048×2048 중앙에 0으로 채워 넣고 unitary FFT를 한다. 0 채움은 Fourier면을 더 촘촘히 샘플링하기 위한 것으로, 새로운 실측 해상도를 만드는 과정은 아니다.

미지수는 위상 계수 12개와 위치 보정 계수 6개, 총 18개다. 3×2 기하 행렬 G에 대해 scan i의 위치 수정은 아래와 같다. q/250은 수치 최적화에서 계수 크기를 다루기 편하게 하는 스케일이다.

\[ \Delta c_i=[q_{xi}/250,q_{yi}/250,1]G,\qquad c_i=[q_{xi},q_{yi},1]A+\Delta c_i. \]

raw 네 이웃을 저장 이미지 좌표로 환산한 위치 p를 사용해 Fourier PSF 좌표 ξ를 계산한다. B=A의 앞 두 행, s=[NFFT·step/Nₓ,NFFT·step/Nᵧ]로 정의하면 다음과 같다.

\[ \xi_i=(p-c_i)B^{-1}\odot s+[N_{\rm FFT}/2,N_{\rm FFT}/2]. \]

이 위치에서 |h|²를 bilinear 보간하고, 다시 raw→저장 이미지의 네 가중치로 합친다. 따라서 모델 Mᵢⱼ는 카메라가 intensity를 resize한 과정을 포함한다. 복소 h를 저장 이미지 한 점으로 먼저 보간하고 나중에 제곱하는 모델과 다르다.

5.4 패턴별 gain과 손실함수#

Dᵢⱼ는 배경 제거된 관측 강도, mᵢⱼ는 유효 픽셀 마스크다. 코드의 고정 가중치 w는 밝은 픽셀에 상대적으로 작은 가중치를 주고, 저신호에서는 9의 바닥값을 둔다. 이는 shot noise와 배경 오차를 고려한 실용적 가중치이며 측정된 완전한 잡음 공분산은 아니다.

\[ w_{ij}=\frac{m_{ij}}{\max(D_{ij}+9,9)},\qquad d_i=\max\!\left(\sum_jw_{ij}D_{ij}^2,10^{-12}\right). \]

패턴마다 조명 세기가 다를 수 있으므로, 공통 PSF 모양 M에 별도 gain gᵢ를 곱한다. 주어진 M에서 gain은 반복 탐색 없이 미분해서 구할 수 있다.

\[ g_i=\frac{\sum_jw_{ij}M_{ij}D_{ij}}{\max(\sum_jw_{ij}M_{ij}^2,10^{-20})}. \]

유도는 Σw(gM−D)²를 g로 미분해 2ΣwM(gM−D)=0으로 놓으면 된다. 코드의 분모 바닥값은 0 나눗셈을 막는다. M과 D가 음이 아니므로 gain도 보통 음이 아니다.

\[ L_{\rm data}=\frac1{n_{\rm train}}\sum_i\frac{\sum_jw_{ij}(g_iM_{ij}-D_{ij})^2}{d_i},\qquad L=L_{\rm data}+\frac{10^{-4}}{12}\sum_{k=1}^{12}a_k^2. \]

각 패턴 손실을 자신의 관측 강도 크기로 나누므로 매우 밝은 패턴만 전체 적합을 지배하는 것을 줄인다. 마지막 항은 위상 계수가 불필요하게 커지는 것을 억제하는 정규화다. fit_summary에 보고되는 loss는 이 정규화 항을 제외한 데이터 손실이다.

5.5 해석적 미분과 반복 최적화#

유한차분으로 18개 변수를 하나씩 바꾸는 대신 Fourier 변환의 선형성을 이용해 미분을 계산한다. Zₖ는 실수 함수이고, 별표는 복소켤레다.

\[ \frac{\partial P}{\partial a_k}=iZ_kP,\qquad \frac{\partial h}{\partial a_k}=\mathcal F\{iZ_kP\},\qquad \frac{\partial |h|^2}{\partial a_k}=2\operatorname{Re}\!\left(h^*\frac{\partial h}{\partial a_k}\right). \]

bilinear 보간의 x 미분은 (f₁₀−f₀₀)(1−β)+(f₁₁−f₀₁)β이고, y 미분은 (f₀₁−f₀₀)(1−α)+(f₁₁−f₁₀)α다. 이 미분과 위치 ξ의 G에 대한 미분을 연쇄법칙으로 곱하면 기하 계수의 gradient가 된다. 초점 중심을 오른쪽으로 이동시키면 상대 샘플 좌표는 왼쪽으로 가므로 위치 Jacobian에는 음수가 들어간다.

\[ \frac{\partial L_{\rm data}}{\partial\theta}=\sum_{i,j}\frac{2w_{ij}(g_iM_{ij}-D_{ij})g_i}{n_{\rm train}d_i}\frac{\partial M_{ij}}{\partial\theta}. \]

여기서 gᵢ의 θ 의존성을 따로 미분하지 않는 이유는 gain이 매번 최적값이어서 그 방향의 1차 미분이 0이기 때문이다. 이를 envelope theorem 관점으로 이해할 수 있다. 분모를 강제로 자르는 극단적인 수치 퇴화 상황은 별도 바닥값 처리다. 위상 정규화의 gradient 2·10⁻⁴·aₖ/12도 더한다.

L-BFGS-B는 현재 gradient와 이전 변화량으로 곡률을 근사하고, 상자형 경계를 지키면서 손실을 줄이는 방향으로 움직인다. 모든 Hessian을 저장하지 않는 limited-memory 방식이다. pupil 계수 경계는 각각 ±2.5 rad, 기하 계수는 각각 ±1.5다. 최대 180회 반복, ftol=10⁻⁹, gtol=10⁻⁵, line search 최대 30을 사용한다. 이 수치는 중단 조건이며 전역 최적해를 보장하는 조건은 아니다 [참고 2].

5.6 표본 분할과 여러 시작점#

유효 초점을 이미지의 8×8 공간 셀과 raw 포화 유무로 층화한다. 각 층에서 번갈아 골라 최대 256개를 취하고 seed=912로 섞은 뒤 약 1/4을 validation으로 둔다. 256개가 모두 있으면 train 192개, validation 64개다. affine은 이 train 점만으로 다시 계산한다. 앞의 전체 초점 affine은 위치 탐색과 품질 선택에 사용된 초기값이다.

평평한 pupil 기준선은 위상 계수를 모두 0으로 고정하고 기하 6개만 최대 70회 적합한다. 본 적합은 표준편차 0.25 rad인 비영 위상으로 3번 시작한다. 대칭인 flat pupil에서는 일부 짝수 위상 변화의 강도 1차 미분이 0이어서 0에서만 시작하면 움직이기 어려운 방향이 생기기 때문이다.

세 결과 중 train 데이터 손실이 가장 작은 것을 고른다. validation 손실로 시작점을 고르는 코드가 아니다. baseline과 fitted의 train 및 validation 손실, optimizer success와 반복 수를 함께 저장한다. 작은 데이터 손실이라도 optimizer success=False일 수 있으므로 두 값은 별도로 읽는다.

5.7 primary와 twin의 비유일성#

pupil을 뒤집고 복소켤레를 취하면 Fourier면의 복소 광장은 원래 광장의 켤레가 된다. 따라서 두 후보는 같은 강도를 만든다.

\[ P_{\rm twin}(u,v)=P^*(-u,-v),\qquad h_{\rm twin}(x,y)=h^*(x,y),\qquad |h_{\rm twin}|^2=|h|^2. \]

Zernike의 반전 대칭은 Zₙᵐ(−u,−v)=(−1)ⁿZₙᵐ(u,v)이므로 twin 계수는 −(−1)ⁿaₙᵐ다. primary는 코드가 선택한 한 후보의 이름이며 ‘실험적으로 참임이 확인됨’을 뜻하지 않는다. 강도 scan만으로 이 둘을 고를 추가 정보가 없어서 이후 TM도 두 branch를 모두 계산한다.

validation_spots.png는 최대 8개 validation 초점의 관측, flat pupil, fitted pupil, 차이를 비교한다. pupil_and_spatial_error.png는 두 위상 후보와 validation 위치별 오차를 보여 준다. 이 그림들은 입력 광장 추정의 진단이며 최종 모드 TM의 대각성 검증은 아니다.

6 입력 복소 광장과 Fourier 특징#

6.1 적합용 격자에서 실제 SLM 격자로#

InputOpticsModel은 pupil_model.npz의 12개 계수로 pupil을 1 SLM 픽셀 간격에서 다시 평가한다. 기본 반경에서는 half=ceil(134.4)+4=139이므로 279×279 pupil이 되고, 이를 4096×4096에 넣어 Fourier 변환한다. 저장된 145×145 pupil 그림을 단순 확대하는 과정이 아니다.

적합용 FFT의 임의 진폭 단위와 맞추기 위해 PSF에 (4096/2048)×(1/2)²=0.5를 곱한다. 이 값은 FFT 크기와 pupil 샘플 간격을 바꾼 데 따른 수치 단위 보정이다. 광학계의 절대 전력 보정값이 아니다.

scan 위상을 중심 좌표로 다시 쓰면 공통 위상 piston이 생긴다. SLM 중심은 코드에서 [Nₓ/2,Nᵧ/2]=[636,512]로 정의한다.

\[ p_i=\phi_i[0,0]+g_{xi}N_x/2+g_{yi}N_y/2=\phi_i[0,0]+\pi(q_{xi}+q_{yi}). \]

따라서 primary 입력은 이동된 h에 exp(ipᵢ)를 곱한 값이고, twin 입력은 이동된 h의 켤레에 동일한 exp(ipᵢ)를 곱한 값이다. exp(ipᵢ)까지 모두 켤레로 바꾸는 정의가 아니다.

InputOpticsModel.field는 기본적으로 반환 광장의 L2 노름을 1로 만든다. 그러나 TM 학습용 Fields는 reference를 기준으로 공통 스케일을 쓰기 위해 normalize=False를 이용한다. 두 정규화 방식을 섞으면 패턴 사이의 상대 크기가 달라진다.

6.2 픽셀에서 물리 좌표로#

Fields는 초점 위치와 scan q 사이의 inverse affine을 이용해 입력 이미지 픽셀을 μm 단위 좌표로 변환한다. fλ/d=202.56 μm는 코드에 고정된 광학값이다.

\[ J=B^{-1}\operatorname{diag}\!\left(\frac{202.56}{1272},\frac{202.56}{1024}\right),\qquad r_{\mu m}=([x,y]-[255.5,255.5])J. \]

J는 2×2 Jacobian으로, 이미지의 한 픽셀 변화가 물리 좌표를 얼마나 바꾸는지 나타낸다. 회전, 서로 다른 축 배율, 비직교성이 모두 들어갈 수 있다. 물리 반경 52.5 μm 이내를 input core_mask로 남긴다. 이 반경은 지름 105 μm 코어라는 고정 사양에 해당한다.

Fourier 주파수는 반대 방향으로 변환된다. ν는 cycles/pixel, κ는 cycles/μm이고, 코드의 행벡터 규약에서는 다음 식을 사용한다.

\[ \kappa=\nu J^{-\mathsf T},\qquad \|\kappa\|\le\frac{NA_{\rm in}}{\lambda}=\frac{0.18}{0.633}\simeq0.28436\ \mu m^{-1}. \]

J가 비등방이면 픽셀 주파수 평면의 선택 영역은 원이 아니라 기울어진 타원 형태가 될 수 있다. 따라서 입력 특징 개수 p는 NA만으로 결정되지 않고 보정 행렬과도 관련된다. 여기서 objective NA 0.42, 입력 특징 NA 0.18, protocol의 fiber NA 0.22는 서로 다른 역할을 한다.

6.3 공통 입력 정규화와 두 branch의 특징#

reference-pattern 2000의 모델 광장을 core_mask로 자른 뒤 norm을 구하고 그 역수를 입력 공통 스케일 sᵢₙ으로 쓴다. 각 scan을 따로 단위 노름으로 만들지 않는다. 따라서 core 밖으로 이동한 초점의 약한 입력 크기도 특징에 반영된다.

\[ s_{\rm in}=\frac1{\|M_{\rm core}E_{p_0}\|_2},\qquad f_i=S_{\rm NA}\mathcal F_{\rm ortho}\{s_{\rm in}M_{\rm core}E_i\}. \]

SNA는 선택 주파수만 뽑는 연산이다. Fields.build는 32개 패턴씩 GPU에서 처리해 n×p complex64 배열을 만든다. twin에는 푸리에 성질 F{E*}(k)=F{E}(−k)*를 사용한다. 음의 주파수 위치를 modulo 512 규약으로 찾아 켤레를 취하고, 두 branch에 같은 piston을 곱한다.

static_features_0.18.npz에는 두 특징 배열과 metadata 및 pupil 파일의 SHA256을 연결한 서명을 저장한다. 같은 서명이면 입력 특징을 재사용한다. 파일 이름의 0.18은 입력 NA 설정이다.

6.4 임의 SLM 위상을 넣는 저장 모델#

StaticTM.field_from_slm_phase는 단순 scan 전용 field 함수보다 일반적인 전방 계산 경로다. 입력 위상을 exp(iφ)로 바꾼 다음, 저장된 pupil 중심 주변에서 복소 파동을 bilinear 샘플링한다. pupil을 곱하고 4096 FFT를 거쳐 512 입력 이미지 좌표로 보간한다.

위상 숫자를 직접 보간하지 않고 exp(iφ)를 보간하는 이유는 −π와 π가 같은 위상을 나타내는 경계이기 때문이다. 두 숫자의 산술 평균은 0이지만 두 파동의 평균은 −1에 가깝다. 다만 복소 파동 보간도 샘플링에 따른 진폭 변화가 생길 수 있다. 코드가 pupil 중심을 정수 SLM 픽셀로 정하는 이유 중 하나다.

반환값에는 core_mask와 공통 scale이 아직 적용되지 않는다. StaticTM.features가 이를 한 번 적용하고 FFT 특징을 만든다. 학습된 scan에 대한 일치 검사는 수행하지만, 임의 SLM 위상의 실험 예측력이 독립 검증된 것은 아니다.

7 출력 위치와 위상 보정#

7.1 이미 복원된 출력 광장을 읽는다#

prepare_outputs는 Eout_expData.npy와 Eout_drift_expData.npy를 복소수 512×512로 읽는다. 최소 두 reference가 필요하다. 원시 출력 BMP의 픽셀값으로 광장을 복원하지 않으며, 그 BMP들은 파일 번호 검증과 수정 시각 추출에 사용된다.

기준 epoch는 첫 reference BMP의 수정 시각이다. scan과 reference의 시각은 (mtime−epoch)/60으로 분 단위로 바꾼다. 각각의 파일열에서 시각이 엄격하게 증가해야 한다. 파일을 복사하거나 다시 저장해 수정 시각이 바뀌면 실제 노출 시각과 달라질 수 있다. 코드도 이를 exposure timestamp라고 주장하지 않는다.

7.2 복소 overlap으로 평행 이동 찾기#

시간에 따라 출력 영상이 조금 이동하면 같은 입력의 reference라도 픽셀별 복소값이 달라진다. register는 reference 0을 기준으로 매 20번째 reference와 마지막 reference를 anchor로 골라 상대 이동을 찾는다.

\[ \mathcal O(a,b)=\frac{|a^{\mathsf H}b|^2}{\|a\|_2^2\|b\|_2^2},\qquad L_{\rm shift}(s)=1-\mathcal O(a,b_s). \]

0≤O≤1이고, b가 a에 상수 진폭과 전역 위상을 곱한 값이면 O=1이다. 따라서 전체 밝기와 전체 위상이 달라도 공간 모양을 비교할 수 있다. 이동 규약은 bₛ[y,x]=b[y−dy,x−dx]다. 양의 dx는 영상 내용을 오른쪽으로 옮기는 보정이다.

비교 픽셀은 중심 [255.5,255.5]에서 반경 215 안을 4픽셀 간격으로 샘플링한다. 32픽셀 정사각 블록을 바둑판처럼 교대로 나눠 한쪽은 적합에, 다른 쪽은 진단에 사용한다. 이는 같은 영상 내부의 공간 분리이며, 새로운 시각에 얻은 독립 관측 검증이 아니다.

후보 광장의 실수부와 허수부를 각각 3차 spline 계수로 바꾸고 이동 위치에서 보간한다. Powell은 gradient 없이 탐색 방향을 따라 손실을 줄이는 알고리즘이다. ±15픽셀 경계 안의 7×7 거친 격자를 평가해 좋은 두 후보, 0 이동, 이전 anchor 해를 시작점으로 쓴다. 각 시작점에서 최대 45회 최적화하고 가장 작은 손실을 고른다. xtol=0.002픽셀, ftol=10⁻⁹이다.

output_motion.json에는 전후 overlap, 최적화 성공 여부, 경계 도달 여부를 저장한다. 이동이 ±15픽셀 가까이에 걸리면 최적 이동이 탐색 범위 밖일 수 있다. 이 평행 이동을 곧바로 물리적 파이버 이동량이라고 해석할 수는 없다.

7.3 PCHIP 시간 보간#

anchor 사이의 dy와 dx는 각각 PCHIP으로 시간 보간한다. PCHIP은 데이터의 국소 단조성을 보존하도록 기울기를 정하는 구간별 3차 Hermite 보간이다. 급격한 과도 진동을 줄이는 성질이 있지만, 실제 드리프트가 항상 그 곡선을 따른다는 보장은 없다 [참고 3].

구간 폭 h=t₁−t₀, 정규화 시간 u=(t−t₀)/h, 끝점 값 v₀,v₁, 끝점 기울기 m₀,m₁이면 보간식은 다음과 같다.

\[ v(t)=(2u^3-3u^2+1)v_0+(u^3-2u^2+u)hm_0+(-2u^3+3u^2)v_1+(u^3-u^2)hm_1. \]

PCHIP은 이웃 구간 기울기의 부호가 다르면 내부 기울기를 0으로 두고, 같은 부호이면 구간 폭을 고려한 조화평균을 사용한다. 코드에서는 SciPy 구현을 호출한다. 첫 reference 이전이나 마지막 reference 이후의 시간은 양 끝으로 잘라서 사용하므로 외삽으로 이동량을 늘리지 않는다.

7.4 Fourier 이동과 출력 주파수 선택#

transform은 전체 출력의 unitary FFT를 계산한 뒤 kᵧ,kₓ=−96,…,95의 192×192 주파수만 남긴다. 저장 벡터 길이는 36864다. 실제 보정 적용은 spline 영상 재생성이 아니라 Fourier shift theorem으로 한다.

\[ \widetilde E_{\rm shifted}[k_y,k_x]=\widetilde E[k_y,k_x]\exp\!\left[-\frac{2\pi i}{512}(k_y\,dy+k_x\,dx)\right]. \]

이 승수의 크기는 1이므로 선택 주파수 각각의 제곱크기는 변하지 않는다. FFT 평행 이동은 주기 경계 규약을 가진다. 앞의 영상 보간을 통한 이동량 추정과 여기의 Fourier 이동 적용은 서로 다른 수치 연산이며, 둘 다 명시한 부호 규약을 따른다.

7.5 reference 사이의 공통 위상 연결#

같은 입력을 반복한 reference에서 남은 전역 위상 변화를 추정한다. 먼저 위치가 보정된 reference 스펙트럼 rⱼ를 사용한다. 보존할 reference 인덱스는 rt에 시간 순서대로 담겨 있다.

\[ \alpha_0=0,\qquad \alpha_j=\alpha_{j-1}+\arg\!\left(r_{j-1}^{\mathsf H}r_j\right). \]

코드에서는 위 식의 j−1,j가 인접한 ‘보존된’ reference를 가리킨다. 제외 reference 사이를 건너뛰는 경우도 있다. rⱼ에 exp(−iαⱼ)를 곱하면 인접 reference의 내적 위상이 0이 되도록 위상 기준이 연결된다. 이를 parallel transport라고 부른다. 회전 좌표계의 기준 방향을 앞 관측과 맞춰 가는 것처럼 이해할 수 있다.

예를 들어 r₁=eⁱ⁰·⁷r₀이면 내적 위상은 0.7 rad이고, exp(−i0.7)을 곱하면 r₀와 위상 기준이 같아진다. 그러나 두 영상의 모양이 크게 달라져 내적이 거의 0이면 그 각도는 잡음에 민감하다. reference_neighbor_diagnostics.json은 overlap이 작은 이웃 쌍 최대 10개를 보여 준다. 코드에는 이 값을 기준으로 reference를 자동 제거하는 임계값이 없다.

scan의 공통 위상은 reference 시간의 α를 선형 보간한다. 위치는 PCHIP, 위상은 np.interp 선형 보간이라는 차이에 주의한다. 인접 간 실제 위상 변화가 π를 넘거나 신뢰할 reference가 부족하면 이 연결만으로 올바른 위상 회전을 알아낼 수 없다. 이 과정은 모든 시간별 모드 결합을 모델링하는 것이 아니라 공통 scalar 위상만 제거한다.

7.6 출력 공통 scale과 저장#

정상 reference의 평균 스펙트럼 에너지가 1이 되도록 공통 진폭 scale sₒᵤₜ을 정의한다. 출력 yᵢ는 이동 보정, 위상 보정, 공통 크기 보정을 거친다.

\[ s_{\rm out}=\sqrt{\frac1{|rt|}\sum_{j\in rt}\|r_j\|_2^2},\qquad y_i=\widetilde E_{i,\rm shifted}\,e^{-i\alpha(t_i)}/s_{\rm out}. \]

reference를 한 장씩 모두 단위 norm으로 만드는 과정이 아니다. 같은 scale을 모든 scan과 reference에 적용하므로 상대 출력 에너지 차이는 남는다. 선택 전 원본 출력 에너지도 같은 scale²로 나누어 total_output_power.npy에 저장한다.

\[ \eta_i=\frac{\|y_i\|_2^2}{P_{i,\rm full}},\qquad P_{i,\rm full}=\frac{\sum_{x,y}|E_i[x,y]|^2}{s_{\rm out}^2}. \]

η는 spectral_retained_fraction이다. 보존한 Fourier 영역이 원래 에너지의 얼마를 포함하는지 뜻하며, 이론적으로 0~1이다. 코드에서는 η≤1+10⁻⁶을 확인한다. η가 작으면 선택 영역 밖의 출력이 많아서 선택된 스펙트럼 안의 좋은 적합만으로 전체 영상 예측이 좋다고 할 수 없다.

outputs.npy는 complex64 memory map으로 순차 저장한다. scan을 먼저, reference를 나중에 놓는다. 제외된 reference도 파일에서 삭제하지 않고 보간된 위상을 적용해 저장하며, 학습 제외 인덱스를 metadata에 따로 둔다. registration anchor 자체를 제외하려 하면 현재 코드는 오류를 낸다. 기본 제외 목록은 빈 목록이다.

7.7 저장 검증과 완료 표시#

출력 전처리는 양의 유한한 full power, Parseval 상한, 정상 reference 평균 에너지 1과의 차이 10⁻⁶ 미만, 이웃 reference 보정 후 위상 잔차 10⁻⁸ rad 미만을 검사한다. 마지막 위상 검사는 알고리즘이 만든 기준에 대한 일치 검사이며 물리적 참 위상의 측정 오차가 아니다.

큰 출력은 .partial 파일로 쓴 뒤 정상 이름으로 바꾼다. metadata.npz는 마지막에 기록해 완료 표지로 쓴다. 재생성할 때 이전 metadata는 metadata.previous.npz로 옮기고 후속 static/modal 완료 표지를 제거한다. 이 방식은 중단된 계산을 완료된 계산으로 오인할 가능성을 줄이지만, 전 과정이 데이터베이스의 단일 원자적 트랜잭션인 것은 아니다.

8 입력 위상 기준과 정적 전달행렬#

8.1 왜 추가 입력 위상 보정이 필요한가#

강도 적합만으로 SLM에서 실제 pupil 중심이 어디인지 완전히 정해지지 않는다. 중심이 Δu,Δv만큼 바뀌면 같은 ramp가 pupil 중심에서 갖는 위상도 달라진다. 이 변화는 q에 선형이다.

\[ \psi_i=2\pi\!\left(\frac{q_{xi}\Delta u}{1272}+\frac{q_{yi}\Delta v}{1024}\right),\qquad f_i\leftarrow e^{i\psi_i}f_i. \]

phase_center는 입력 특징 사이의 내적 위상과 출력 사이의 내적 위상이 잘 맞는 Δu,Δv를 찾는다. 이는 ‘출력 정보를 전혀 안 쓰는 입력 추정’은 아니다. calibration 출력은 여기와 TM 학습에 사용한다. 사용하지 않는 것은 별도 target 출력이다.

8.2 가까운 scan 쌍으로 중심 찾기#

유효한 일반 scan의 초점 중심을 cKDTree에 넣고 거리 16픽셀 이내의 쌍을 찾는다. 입력 Gram K=FFᴴ와 출력 Gram G=YYᴴ에서 아래 정규화 값을 계산한다. 관측이 행이라는 규약 때문에 이 Gram 원소는 해당 행과 다른 행의 켤레를 곱한 값이다.

\[ a_{ij}=\frac{K_{ij}}{\sqrt{K_{ii}K_{jj}}},\qquad b_{ij}=\frac{G_{ij}}{\sqrt{G_{ii}G_{jj}}},\qquad z_{ij}=\frac{b_{ij}a_{ij}^*}{|b_{ij}a_{ij}^*|}. \]

|a|>0.003, |b|>0.03인 쌍만 남긴다. weight는 |ba*|를 전체 합으로 나눈 값이다. 기하 설계 행 dᵢⱼ=(qᵢ−qⱼ)⊙[2π/1272,2π/1024]에 대해 원형 위상 손실을 최소화한다.

\[ L(c)=-\sum_{ij}w_{ij}\operatorname{Re}\!\left[z_{ij}e^{-i d_{ij}c}\right],\quad \nabla L(c)=-\sum_{ij}w_{ij}\operatorname{Im}\!\left[z_{ij}e^{-i d_{ij}c}\right]d_{ij}. \]

최소 세 쌍, 설계 행렬 rank 2가 필요하다. x,y 각각 −40,0,40으로 9번 시작하고 ±50 SLM 픽셀 안에서 L-BFGS-B로 찾는다. 가장 좋은 연속 해를 정수로 반올림해서 사용한다. 이는 실제 phase-only SLM의 샘플 중심과 맞추려는 선택이다.

여기서 얻은 중심은 출력 위상 기준 및 ramp 격자 alias에 조건부인 보정값이다. 단 하나의 실제 물리 pupil 중심을 독립 측정한 결과가 아니다. 코드에는 입력의 시간 이동, q의 2차 위상항, 시간 커널이 들어 있지 않다.

8.3 실제 회귀에 포함되는 데이터#

fit_static은 모든 일반 scan과 제외되지 않은 reference를 사용한다. 입력 valid=False인 일반 scan도 학습에 포함한다. 각 reference는 같은 입력 특징을 가진 반복 행으로 들어가므로, reference가 많으면 그 입력 방향에 대한 잔차가 목적함수에서 반복해서 가중된다.

TM 단계에는 독립적인 held-out calibration split이 없다. metadata의 roles는 전부 0이며, pupil 단계의 train/validation 구분을 TM 단계에 이어서 쓰지 않는다. 따라서 static_checks의 training_fit_only는 학습 데이터 재현 오차다.

8.4 복소 ridge 회귀의 유도#

학습에 포함된 행만 모은 입력 F를 nfit×p, 출력 Y를 nfit×o라 하자. o=36864다. 코드에서 풀 미지수 W는 p×o이고 저장할 전달행렬은 T=Wᵀ이다. 입력 평균 에너지 s를 정규화 강도의 척도로 쓴다.

\[ s=\frac1{n_{\rm fit}}\sum_i\|f_i\|_2^2,\qquad W=\arg\min_W\left(\|FW-Y\|_F^2+s\|W\|_F^2\right). \]

protocol의 regularization=1은 단순히 모든 경우에 I만 더한다는 의미가 아니다. 실제 행렬에는 입력 평균 에너지 s에 1을 곱한 sI가 더해진다. s를 p로 한 번 더 나누지도 않는다.

복소 미지수의 실수부와 허수부에 대해 미분하거나 W*에 대한 미분을 사용하면 아래 정규방정식이 나온다. 모든 출력 열에 같은 왼쪽 행렬이 쓰인다.

\[ (F^{\mathsf H}F+sI_p)W=F^{\mathsf H}Y,\qquad T=\left[(F^{\mathsf H}F+sI_p)^{-1}F^{\mathsf H}Y\right]^{\mathsf T}. \]

정규화가 없고 F의 열이 서로 비슷하면 아주 작은 측정 변화가 큰 계수 변화로 이어질 수 있다. sI는 그런 불안정한 역문제를 완화한다. 동시에 계수를 줄이는 bias를 만들기 때문에 학습 잔차가 0이 되지 않는 것이 정상이다.

학습용 1변수 예제에서 f=[1,2], y=[2,4]라 하자. s=(1²+2²)/2=2.5이고 w=(1×2+2×4)/(1²+2²+2.5)=10/7.5=1.333…이다. 참 관계 y=2f인 잡음 없는 예제라도 ridge를 쓰면 계수가 2보다 작아진다. 이 예제는 코드의 s 정의를 확인하기 위한 것이며 실험 결과가 아니다.

8.5 구현에서 역행렬 대신 연립방정식을 푼다#

수식에는 역행렬을 썼지만 실제 코드는 FᴴF+sI를 complex128로 만들고 LU 분해를 한 번 수행한다. LU는 행렬을 삼각행렬들의 곱으로 분해해 여러 오른쪽 항을 효율적으로 푸는 방법이다. 출력 열은 4096개씩 나누어 같은 분해로 해결한다.

각 블록에서 상대 정규방정식 잔차 ||GW−RHS||/||RHS||<10⁻¹⁰을 확인한다. 큰 계산의 중간값은 complex128을 쓰고 저장 시 T와 특징을 complex64로 바꾼다. complex64는 실수부와 허수부가 각각 32비트이므로 원소당 8바이트다. 저장 오차를 별도로 검사하는 이유다.

8.6 독립된 primal과 dual 식의 비교#

같은 ridge 해는 입력 특징 크기 p의 방정식과 관측 수 nfit의 방정식으로 각각 쓸 수 있다. 이를 비교하면 전치, 켤레, 스케일의 실수를 잡는 데 도움이 된다.

\[ \widehat y_*=f_*F^{\mathsf H}(FF^{\mathsf H}+sI)^{-1}Y. \]

코드에서는 K=FFᴴ/s+I, cross=f*Fᴴ/s를 만들어 cross K⁻¹Y를 구한다. 정적 행렬을 직접 곱한 결과와 선택한 샘플 및 매 73번째 출력 열에서 상대오차 10⁻⁹ 미만인지 비교한다. 서로 다른 식의 수치적 일치를 확인하는 것이지, 실험 모델이 참이라는 검증은 아니다.

9 학습 오차와 저장 모델 사용#

9.1 세 가지 오차 지표#

static_checks는 일반 scan과 reference를 구분해 지표를 집계한다. Fourier NMSE는 보존한 출력 주파수 안에서 잔차 에너지 합을 관측 에너지 합으로 나눈 값이다. 패턴별 NMSE의 단순 평균이 아니라 에너지 합의 비율이다.

\[ \mathrm{NMSE}_{F}=\frac{\sum_i\|y_i-\widehat y_i\|_2^2}{\sum_i\|y_i\|_2^2}. \]

전체 카메라 NMSE는 선택 주파수 밖의 예측을 0으로 가정한다. Fourier 좌표가 직교하므로 보존 영역 오차와 버린 영역 에너지를 더할 수 있다. 집계 오차에서 작은 음수는 0으로 자른다.

\[ \mathrm{NMSE}_{\rm full}=\frac{\sum_i\|y_i-\widehat y_i\|_2^2+\max(\sum_iP_{i,\rm full}-\sum_i\|y_i\|_2^2,0)}{\sum_iP_{i,\rm full}}. \]

mean_overlap_squared는 프레임별 |yᴴŷ|²/(||y||²||ŷ||²)의 산술 평균이다. NMSE는 크기와 위상 오차에 반응하지만 overlap은 전체 복소 배율에 둔감하다. 예측이 실제의 두 배이면 overlap은 1일 수 있어도 NMSE는 0이 아니다.

9.2 파일을 다시 읽는 검증#

저장된 StaticTM으로 특징을 곱한 결과와 저장 전 complex128 계산을 비교해 상대오차 2×10⁻⁵ 미만을 확인한다. 또 유효 scan 인덱스 목록의 10%, 50%, 90% 위치에서 고른 세 패턴과 reference 패턴의 실제 SLM 위상을 별도 전방 경로에 넣고, 학습 특징과 상대오차 0.005 미만인지 비교한다. 가장 약한 끝점 입력을 피하려는 표본 선택이며 실제 위치 좌표의 분위수를 직접 구하는 코드는 아니다.

이 검증은 저장 파일, 좌표, mask와 scale, 실제 ramp 전방 경로가 서로 일관적인지 확인한다. 약하거나 가장자리인 입력 전체의 모델 정확도를 검증하는 것은 아니며, 참 입력 위상을 외부 측정과 비교하는 것도 아니다.

9.3 정적 연산자를 쓰는 순서#

이미 정규화된 Fourier 특징을 갖고 있다면 predict_spectra만 호출한다. 원시 복소 입력 이미지라면 features를 호출한다. SLM 위상이라면 field_from_slm_phase → features → predict_spectra 순서다. 아래는 API 사용 예이며 이 문서 작성 중 실행한 계산은 아니다.

from tm_utils import OUT, StaticTM
import numpy as np

api = StaticTM(OUT / 'primary' / 'static', use_gpu=False)
phase = np.load('my_phase.npy')  # 1024 x 1272, radians
field = api.field_from_slm_phase(phase)
features = api.features(field)
spectra = api.predict_spectra(features)  # (1, 36864)

출력은 192×192의 선택 Fourier 계수다. 512×512 복소 영상으로 보려면 선택 위치에 계수를 넣고 나머지를 0으로 둔 후 ifftshift와 unitary inverse FFT를 적용한다. 이 복원은 버린 주파수를 0으로 둔 대역 제한 영상이며 원본의 모든 세부를 복구하지 못한다.

freq = api.coordinates['output_frequency_yx']
full = np.zeros((512, 512), dtype=np.complex64)
full[freq[:, 0] + 256, freq[:, 1] + 256] = spectra[0]
output_field = np.fft.ifft2(np.fft.ifftshift(full), norm='ortho')
output_intensity = abs(output_field) ** 2

코드 주석 중 features()/apply()라고 적힌 곳이 있지만 현재 StaticTM 클래스에는 apply 메서드가 없다. 위 예제처럼 실제로 존재하는 메서드를 연결한다. OUT과 다른 측정의 pupil, 입력 특징, operator.json을 섞지 않는다.

10 모드 사전을 만드는 계산#

10.1 카탈로그와 관측 사전은 다르다#

카탈로그는 모드의 번호, 전파상수 beta, 방위 차수 l, 방사 차수 m, family, 파장, 코어 지름과 굴절률 등을 제공한다. load_catalog는 파일을 읽고 generator_version이 현재 모드 유틸리티의 버전 문자열과 맞는지 검사한다. 이 문서에서는 카탈로그의 고유값 탐색이나 벡터장 공식 자체를 유도하지 않는다.

모드 사전은 그 모드를 실제 입력 또는 출력 관측 좌표에 샘플링한 열벡터들을 나란히 놓은 행렬이다. 같은 카탈로그를 써도 crop, 배율, 편광 선택, NA, 격자, 정규화가 달라지면 사전은 달라진다. 카탈로그 재사용과 관측 사전 재사용을 구분해야 한다.

modal 단계는 primary의 정적 좌표와 입력 core_mask로 shared_basis를 만들고, 이를 primary와 twin에 공통으로 사용한다. 두 branch마다 새로 다른 모드 카탈로그를 고르는 구조가 아니다.

10.2 출력 crop에서 물리 반경 계산#

cropdata_out.csv의 가로·세로 길이가 같고 150 이상인지 검사한다. crop 한 변의 raw 픽셀 수를 L이라 하면 nominal 물리 반경은 카메라 pitch 3.45 μm, 배율 50으로 계산한다.

\[ R_{\rm cam}=\frac{L\times3.45\ \mu m}{50\times2}. \]

이 식은 코드의 명목 배율 가정이다. 렌즈형 출사면으로 실제 배율이나 좌표 대응이 달라져도 이 코드가 자동으로 추정해 주지 않는다. 아래 모드 정규화에도 이 Rcam이 들어간다. 같은 모드 카탈로그라도 crop이 바뀌면 계수 단위에 영향을 줄 수 있다.

10.3 radial_fields의 수치 정규화#

MMFEHHEfields_fast가 돌려준 Eᵣ,Eφ를 이용해 radial_fields가 모드의 스케일을 정한다. 모드 k의 정규화 상수는 관측 원 Rcam 안의 transverse 벡터장 제곱크기 적분의 제곱근이다.

\[ N_k^2=\int_0^{R_{\rm cam}}2\pi r\left(|E_{r,k}(r)|^2+|E_{\phi,k}(r)|^2\right)dr,\quad E_{r,k}\leftarrow E_{r,k}/N_k,\quad E_{\phi,k}\leftarrow E_{\phi,k}/N_k. \]

이는 Eᵣ와 Eφ 두 성분의 상대 L2 정규화다. 자기장이나 Poynting 벡터를 적분한 실제 watt 정규화는 아니다. 뒤에서 H=Eₓ 성분만 고르더라도 이 벡터 정규화를 유지한다. 따라서 각 H 성분의 norm이 모두 1이 되는 것은 아니다.

적분은 Gauss–Legendre 구적법으로 계산한다. [−1,1]의 노드 ξⱼ와 가중치 wⱼ를 [a,b]로 옮겨 다음처럼 사용한다. 다항식을 정해진 노드에서 평가해 적분을 근사하는 방법이다.

\[ r_j=\frac{a+b}{2}+\frac{b-a}{2}\xi_j,\qquad \int_a^b f(r)dr\simeq\frac{b-a}{2}\sum_jw_jf(r_j). \]

코어 구간 0~min(a,Rcam)은 512노드, Rcam>a이면 클래딩 구간 a~Rcam은 128노드를 쓴다. a는 코어 반경이다. 각 노드 가중치에 2πr을 더 곱한다. Nₖ가 양의 유한값이 아니면 오류를 낸다.

장 값을 빠르게 재사용하려고 코어에 2049개, 클래딩에 513개 등간격 노드를 따로 만든다. 관측 crop이 코어보다 작아도 입력 격자를 평가할 수 있도록 최소한 코어 전체를 tabulation한다. 클래딩 첫 노드는 nextafter(a,+∞)로 경계의 바깥쪽 값을 사용한다. 유전체 경계에서 Eᵣ가 불연속일 수 있어 경계를 가로질러 한 다항식으로 보간하지 않기 때문이다.

카탈로그의 l≥0 모드만 외부 필드 함수를 호출하고, 음의 l은 family, |l|, m으로 대응시킨다. 8개 작업 스레드로 방사장 생성을 병렬화한다. radial_fields.npz의 재사용은 카탈로그 전체 배열 해시, generator_version, normalization_radius가 같을 때 허용된다.

10.4 네 점 Lagrange 보간#

모드가 필요한 픽셀의 반경은 등간격 radial table의 노드와 일반적으로 일치하지 않는다. interpolation_geometry는 반경을 실수 인덱스 t로 바꾸고, floor(t)−1에서 시작하는 네 노드를 선택한다. 시작 인덱스가 범위를 벗어나지 않게 자른 뒤 s=t−index로 아래 가중치를 계산한다.

\[\begin{split} \begin{aligned}w_0&=-(s-1)(s-2)(s-3)/6,&w_1&=s(s-2)(s-3)/2,\\w_2&=-s(s-1)(s-3)/2,&w_3&=s(s-1)(s-2)/6.\end{aligned} \end{split}\]

보간값은 Σⱼ₌₀³wⱼE[index+j]다. 네 점을 지나는 3차 다항식이며 원본 노드에서는 해당 값을 그대로 반환한다. 코어와 클래딩 보간을 별도로 계산한 뒤 r≤a 조건으로 선택한다. 단순 bilinear 보간과 혼동하지 않는다.

10.5 H 성분과 음의 방위 차수#

h_fields는 각 픽셀의 반경 r와 각도 θ를 계산하고 방사장 표를 보간한 뒤 Cartesian x 성분을 만든다. 여기서 코드의 H는 수평 편광인 Eₓ를 뜻한다. 자기장 H벡터를 뜻하는 기호와 다르다.

\[ E_{x,k}(r,\theta)=\left[E_{r,k}(r)\cos\theta-E_{\phi,k}(r)\sin\theta\right]e^{i l_k\theta}. \]

음의 l에는 저장한 양의 |l| 필드로부터 Eᵣ에 (−1)^|l|, Eφ에 −(−1)^|l|를 곱하는 규약을 적용한다. 마지막에 공간 mask를 곱한다. 이 부호와 모드 순서는 카탈로그 규약의 일부이므로 바꾸면 행렬 원소의 위상과 순서도 바뀐다. 기본 32모드씩 생성해 메모리를 제한한다.

여러 벡터 모드가 H 성분만 보면 비슷해질 수 있다. 따라서 모든 카탈로그 모드의 H 성분을 나열한 사전은 중복되거나 매우 약한 방향을 가질 수 있다. 모드 개수 M과 독립적으로 관측·제어할 수 있는 차원을 같은 숫자로 보면 안 된다.

10.6 입력 모드 사전#

입력 물리 격자는 J로 만들며 μm를 m로 바꾼다. 픽셀 면적은 |det J|×10⁻¹² m²다. 연속장 적분을 이산 제곱합으로 근사하기 위해 광장에 면적의 제곱근을 곱한다.

\[ C_{\rm in}[:,k]=S_{\rm NA}\mathcal F_{\rm ortho}\{M_{\rm core}E_{x,k}\}\sqrt{\Delta A},\qquad \Delta A=|\det J|10^{-12}\ {\rm m}^2. \]

이렇게 p×M 행렬을 만든다. 어떤 모드 계수 열벡터 a를 주면 입력 Fourier 특징은 Cᵢₙa다. 사전 정의에는 실험 입력 모델의 sᵢₙ을 곱하지 않는다. 일반 StaticTM.features API로 동일한 모드장을 넣으려면 원시 광장 단위에 √ΔA/sᵢₙ을 반영해야 한다. 그 변환값은 modal operator.json의 input_raw_API_field_factor에 저장된다.

11 출력 카메라 모델과 관측 가능한 조합#

11.1 출력 모드 사전에 카메라 모델이 필요한 이유#

정적 TM의 출력은 카메라 전처리를 거친 192×192 Fourier 계수다. 파이버 단면의 이상적인 모드장을 그 좌표와 바로 내적하면 crop, 필터, resize 때문에 서로 다른 물리량을 비교하게 된다. build_bases는 외부에서 얻은 모드장에 이 전처리 연산을 적용해 출력 사전을 만든다.

다음 카메라 연산은 저장 데이터의 이전 처리 규약을 재현하는 수치 모델이다. 이 프로젝트에서 모든 원시 출력 영상을 다시 복원해서 그 규약을 독립적으로 확인하는 과정은 아니다.

11.2 출력 물리 격자와 Hann 창#

512×512 격자는 [255.5,255.5] 중심, 간격 Δx=2Rcam/512로 만든다. 반경 Rcam의 원형 mask를 적용한다. 모드의 중심 공간 배열에 ifftshift를 하고 unitary FFT한 뒤, 중심 150×150 주파수 −75,…,74를 선택한다. 각 축에 np.hanning(150)을 곱한다.

\[ h_j=\tfrac12\left[1-\cos\left(\frac{2\pi j}{149}\right)\right],\quad j=0,\ldots,149,\qquad H_{jk}=h_jh_k. \]

Hann 창은 주파수 patch 끝을 부드럽게 0으로 줄인다. 높은 주파수의 경계가 급격히 잘리는 현상을 줄이지만 정보와 에너지도 바꾼다. 추가로 exp[−iπ(kᵧ+kₓ)/512] 위상과 Δx를 곱한다. 이는 샘플 중심 및 물리적 면적 정규화 규약의 일부다.

11.3 raw에서 512로 가는 복소 resize 행렬#

output_camera_factors는 150개 Fourier 성분이 raw 카메라에 형성한 복소장을 선형 보간해 512픽셀로 만드는 행렬 W를 구성한다. 실제 raw patch 배치 인덱스는 −76,…,73이다. 모드에서 선택한 −75,…,74와 1 bin 차이가 나는 것은 코드가 재현하는 기존 patch 배치 규약이다.

출력 픽셀 j가 가리키는 raw 위치를 uⱼ=j(L−1)/511, 정수부를 ℓⱼ, 소수부를 βⱼ, raw 중심을 o=(L−1)/2라 두자. Fourier 성분 vₘ=m−76, m=0,…,149에 대해 다음 식이다.

\[ W_{jm}=\frac{(1-\beta_j)e^{2\pi i(\ell_j-o)v_m/L}+\beta_je^{2\pi i(\ell_j+1-o)v_m/L}}{\sqrt{512}}. \]

W의 크기는 512×150이다. 150×150 복소 주파수 patch A로부터 resize된 영상은 WAWᵀ이다. 두 축의 독립적인 선형 보간이므로 오른쪽은 켤레 전치가 아니라 전치다. 여기는 복소 광장 resize이며, 앞의 입력 카메라 강도 resize와 다르다.

11.4 QR 분해로 압축 좌표 만들기#

W의 각 열에 1차원 unitary FFT를 적용하고 −96,…,95의 192개 행만 남긴 행렬을 Wf라 하자. reduced QR 분해를 하면 Q는 192×150, Rc는 150×150이다.

\[ W_f=Q R_c,\qquad Q^{\mathsf H}Q=I_{150},\qquad Y_{192}=Q(R_c A R_c^{\mathsf T})Q^{\mathsf T}. \]

Q는 raw→512 전처리로 만들 수 있는 출력의 1차원 직교 좌표다. 두 축에서 150×150=22500개의 압축 좌표를 쓰면 36864 출력 계수를 모두 큰 행렬로 다루는 부담을 줄일 수 있다. QR 압축 자체는 이 Wf가 표현하는 공간에서 정확한 좌표 변경이다. 뒤의 모드 SVD 절단과는 별개다.

resize_check는 seed=613의 임의 150×150 복소 patch를 만들어 raw 배열에 실제로 배치하고 inverse FFT → scipy zoom(order=1, grid_mode=False)를 실행한 결과와 WAWᵀ를 비교한다. 이어 실제 선택 Fourier 계수와 Q(Rc A Rcᵀ)Qᵀ도 비교한다. 각각 상대오차 10⁻¹⁰ 미만이어야 한다. SciPy zoom의 grid_mode=False는 픽셀 중심 간 거리를 기준으로 한다 [참고 4].

11.5 압축된 출력 모드 사전#

각 H 모드의 필터링된 150×150 patch를 Aₖ라 하자. 출력 사전의 k번째 열은 Rc Aₖ Rcᵀ를 C 순서로 펼친 벡터다.

\[ C_{\rm out}[:,k]=\operatorname{vec}_C(R_c A_kR_c^{\mathsf T}),\qquad C_{\rm out}\in\mathbb C^{22500\times M}. \]

전체 카메라 좌표로의 확장 연산을 B라고 이름 붙이면 B(z)=vecC[Q reshape₁₅₀(z) Qᵀ]다. B는 행렬을 명시적으로 만들지 않고 두 번의 작은 행렬 곱으로 구현한다. 아래에서는 원래 affine B와 혼동하지 않도록 이 카메라 확장을 수식에서 ℬ로 쓴다.

11.6 SVD의 의미#

특잇값 분해 SVD는 사전 C를 서로 직교하는 방향과 그 방향의 관측 세기로 나눈다. U의 열은 관측 좌표의 직교 패턴, V의 열은 원래 모드 계수들의 조합, σ는 그 조합이 관측되는 크기다.

\[ C=U\Sigma V^{\mathsf H},\qquad U^{\mathsf H}U=I,\quad V^{\mathsf H}V=I,\quad \Sigma=\operatorname{diag}(\sigma_1,\sigma_2,\ldots). \]

σ가 작으면 서로 다른 모드 조합이 관측에서 거의 구별되지 않는다. 그런 방향에서 역수를 취하면 작은 측정오차가 크게 증폭된다. 코드에서는 σ>0.01·σmax인 방향만 남긴다. 1%는 고정된 수치 선택이고, 측정된 잡음 바닥이나 통계적 유의수준으로 결정한 값은 아니다.

입력에서는 CᵢₙCᵢₙᴴ의 고유값 분해로 Uᵢ를 구하고 σᵢ=√max(eigenvalue,0), Vᵢ=CᵢₙᴴUᵢ/σᵢ를 계산한다. 출력에서는 CₒᵤₜᴴCₒᵤₜ로 Vₒ를 구하고 Uₒ=CₒᵤₜVₒ/σₒ를 계산한다. 입력과 출력에서 더 적합한 크기의 Gram 행렬을 택한 구현이다.

Gram을 쓰면 원래 C의 조건수가 제곱되는 특성이 있다. 코드에서는 complex128로 계산하고 음의 반올림 고유값을 0으로 자른다. 남긴 U와 V의 직교성 최대 오차가 10⁻⁸보다 작은지 검사한다. 이 구현이 매우 작은 모든 특잇값을 정확히 측정하는 장치라는 뜻은 아니다.

11.7 특잇값 절단 예제#

학습용 사전의 특잇값이 [10,1,0.03]이라면 cutoff는 0.1이다. 앞의 두 방향만 남고 0.03 방향은 버려진다. 원래 모드가 세 개여도 남는 독립 조합은 두 개다. 버린 방향은 마지막 모드 하나와 동일할 필요가 없으며, V의 열이 나타내는 여러 모드의 선형 조합일 수 있다.

basis_checks의 relative_squared_truncation은 1−Σkept σ²/Σall σ²다. 사전 자체의 제곱 Frobenius 크기 중 잘린 비율이며, 실험 출력 광파워 중 잘린 비율과 같은 값은 아니다.

12 정적 TM을 모드 좌표로 바꾸기#

12.1 먼저 입력 좌우 반전 규약을 맞춘다#

modal 계산은 입력 영상을 Enew[y,x]=Eold[y,511−x]로 정의한다. 이 반전은 Fourier 열 순서만 바꾸는 연산이 아니다. 511−x와 −x의 차이 때문에 한 픽셀에 해당하는 위상도 들어간다.

\[ \widetilde E_{\rm new}(k_y,k_x)=e^{2\pi i k_x/512}\widetilde E_{\rm old}(k_y,-k_x). \]

reflected_input_coordinates는 kx의 부호를 뒤집고 새 flat index 순서로 정렬한 뒤 exp(2πikx/512)를 저장한다. NA support와 core_mask도 함께 옮긴다. affine 때문에 support가 기울어진 경우 반전 전후 동일한 index 집합이라고 가정하고 교집합만 남기면 정보를 잃을 수 있다.

입력 특징 열벡터에서 이 변환을 ℛ이라 쓰자. 모드 좌표의 입력을 받는 정적 행렬은 T′=Tsourceℛ⁻¹이다. 코드에서는 source 열을 순서대로 재배치하고 해당 위상으로 나눈다. 이후 원래 특징으로 되돌리는 API도 같은 정보로 역변환한다.

12.2 출력 압축과 모드 부분으로의 투영#

앞 장의 카메라 확장 ℬ는 Q로 150×150 압축 계수를 192×192 출력으로 보낸다. 그 켤레 전치 ℬᴴ는 반대로 QᴴYQ를 계산해 압축한다. 오른쪽 Q는 원소별 켤레이며 차원을 확인하면 192×150이다.

\[ T_c=\mathcal B^{\mathsf H}T',\qquad H=U_o^{\mathsf H}T_c. \]

Tc는 22500×p, H는 rₒ×p다. H는 입력 Fourier 특징을 남겨 둔 출력 직교 모드 채널로 보낸다. 파일 이름은 features_to_output_channels.npy다. Uₒᴴ가 사전이 표현하는 출력 부분만 추출하므로 여기에서 출력 모드 투영이 일어난다.

12.3 세 종류의 모드 행렬#

입력 사전의 남긴 분해를 UᵢΣᵢVᵢᴴ, 출력 사전의 남긴 분해를 UₒΣₒVₒᴴ로 쓴다. 세 행렬은 아래처럼 정의한다.

\[ T_{\rm orth}=U_o^{\mathsf H}T_cU_i=HU_i. \]

정규직교 채널 행렬 Torth는 입력 관측 공간의 Uᵢ 진폭을 출력 관측 공간의 Uₒ 진폭으로 보낸다. 크기는 rₒ×rᵢ다. 파일은 T_orthonormal_H_channels.npy다. 이미지를 그릴 때 사용하는 원래 모드 번호 행렬과는 다르다.

\[ T_{\rm obs}=\Sigma_o^{-1}T_{\rm orth}\Sigma_i. \]

observable 행렬은 원래 모드 계수 공간에서 Vᵢ 조합의 진폭을 Vₒ 조합의 진폭으로 보낸다. 같은 rₒ×rᵢ 크기여도 σ의 배율이 들어가므로 Torth와 원소 크기가 다르다. 파일은 T_mode_observable_H.npy다.

\[ T_{\rm original}=V_o\Sigma_o^{-1}U_o^{\mathsf H}T_cC_{\rm in}. \]

original 행렬은 원래 카탈로그 순서의 M개 입력 H 모드 계수를 M개 출력 H 모드 계수로 보낸다. 파일은 T_mode_original_H.npy이며 최종 비교 그림은 이 행렬을 사용한다. 출력 계수는 남겨 둔 출력 사전의 pseudoinverse로 얻는 최소 노름 계수다.

코드의 original 식에는 전체 Cᵢₙ이 들어간다. 입력 SVD에서 1% 이하 방향을 잘랐다고 original 계산에서 Cᵢₙ을 자동으로 절단한 것으로 설명하면 틀린다. 입력 절단은 Torth와 Tobs의 입력 차원을 정의하는 데 쓰이며, original은 출력 pseudoinverse 절단을 사용하면서 전체 입력 사전을 곱한다.

|파일|크기|입력 좌표|출력 좌표| |T_static_branch.npy|36864×p|원래 입력 Fourier 특징|선택 출력 Fourier 특징| |features_to_output_channels.npy|rₒ×p|반전된 입력 Fourier 특징|출력 Uₒ 채널| |T_orthonormal_H_channels.npy|rₒ×rᵢ|입력 Uᵢ 채널|출력 Uₒ 채널| |T_mode_observable_H.npy|rₒ×rᵢ|입력 Vᵢ 모드 조합|출력 Vₒ 모드 조합| |T_mode_original_H.npy|M×M|원래 H 모드 계수|최소 노름 출력 H 모드 계수| |T_output_residual.npy|36864×p|반전된 입력 Fourier 특징|모드 부분 밖 출력 Fourier 특징|

12.4 pseudoinverse를 왜 쓰는가#

중복된 모드 사전에서는 같은 관측장을 만드는 계수가 여러 개일 수 있다. 예를 들어 사전이 [1,1]이고 관측값이 2이면 계수 [2,0], [1,1], [0,2]가 모두 같은 관측을 만든다. 최소 노름 해는 이 중 제곱합이 가장 작은 [1,1]이다.

절단 pseudoinverse는 남긴 특잇값만 역수로 만든다. 이 연산은 관측 가능한 부분에서 최소제곱 오차가 작고 계수 norm이 작은 해를 고른다.

\[ C_{\rm out,\tau}^{+}=V_o\Sigma_o^{-1}U_o^{\mathsf H},\qquad T_{\rm original}=C_{\rm out,\tau}^{+}\mathcal B^{\mathsf H}T_{\rm source}\mathcal R^{-1}C_{\rm in}. \]

계수 크기는 사전의 열 스케일, 모드 정규화, 작은 σ의 역수에 민감하다. 따라서 original 행렬의 |Tjk|²를 독립적인 모드 간 실제 전력 전달 확률로 해석하려면 현재 코드가 제공하지 않는 추가 조건을 확인해야 한다.

12.5 모드로 표현되지 않은 잔차를 보존한다#

남긴 출력 모드 공간으로 표현되는 정적 행렬을 Trepresented라 하면 잔차는 다음과 같다.

\[ T_{\rm represented}=\mathcal B U_oU_o^{\mathsf H}\mathcal B^{\mathsf H}T',\qquad T_{\rm residual}=T'-T_{\rm represented}. \]

이 잔차에는 출력 모드 사전으로 표현되지 않는 부분, 1% cutoff로 잘린 출력 방향, camera QR 부분공간 밖 성분 등이 포함될 수 있다. ‘추가 파이버 모드의 계수’라는 의미가 아니라 선택 Fourier 좌표에 남은 복소 출력이다.

ModalTM.predict_spectra는 기본 include_residual=True라서 모드 표현과 잔차를 더한다. 따라서 원래 정적 TM 예측을 보존한다. 이 합이 잘 맞는다는 사실만으로 모드 사전이 출력 대부분을 설명한다고 결론 내릴 수 없다. 잔차가 크더라도 합은 맞을 수 있기 때문이다.

source_operator_modal_output_squared_fraction은 ||Trepresented||F²/||T′||F²다. 정적 연산자 제곱크기 중 모드 출력 부분이 차지하는 비율이며, 특정 실험 입력의 출력 에너지 비율과는 다르다. 실제 입력별 모드 설명력을 보려면 그 입력을 곱한 출력과 잔차를 따로 비교해야 한다.

12.6 modal 검증과 API#

modal_checks는 네 가지를 검사한다. 다섯 개 calibration 특징에서 모드+잔차 예측이 정적 TM 예측과 일치하는지, 입력 좌표 변환을 왕복하면 원상복귀하는지, 임의 복소 모드 계수의 original 행렬 적용이 직접 사전 투영과 일치하는지, 남긴 Vᵢ 조합에 대한 observable과 original 적용이 일치하는지 확인한다. 모두 상대오차 2×10⁻⁵ 미만이어야 한다.

from tm_utils import OUT, ModalTM
modal = ModalTM(OUT / 'primary' / 'modal')
f_modal = modal.features_from_source_features(features)
y_preserved = modal.predict_spectra(f_modal)
y_modal_only = modal.predict_spectra(f_modal, include_residual=False)

원래 모드 계수 a를 쓰려면 input_modes_to_features(a), apply_modes(a)를 사용한다. observable 입력은 원래 M개 계수가 아니라 rᵢ개 Vᵢ 조합 계수다. output_modes_to_spectra는 출력 계수에 Vₒ 켤레와 σₒ를 곱해 채널로 옮기고 Uₒ와 Q를 통해 실제 선택 스펙트럼으로 확장한다. array 메서드는 큰 배열을 필요할 때 읽고, 공통 배열은 shared_basis에서 찾아 캐시한다.

13 최종 그림과 대각 성분의 의미#

13.1 그림에 표시하는 값#

plot_dataset_tm은 primary와 twin의 T_mode_original_H.npy를 memory map으로 읽는다. complex64 값을 읽되 제곱과 합은 float64로 계산한다. 큰 M×M 배열 전체의 power 사본을 만들지 않고 320행씩 처리한다.

10×10 블록마다 먼저 각 원소의 크기를 제곱한 뒤 평균한다. 블록 좌표 a,b의 그림 값은 다음과 같다.

\[ P_{ab}=\frac1{100}\sum_{u=0}^{9}\sum_{v=0}^{9}|T_{10a+u,\,10b+v}|^2. \]

복소 원소를 평균한 뒤 제곱하는 |mean T|²가 아니다. 예를 들어 [1,−1]의 제곱크기 평균은 1이지만 복소 평균의 제곱은 0이다. 위상 상쇄를 그림에 섞지 않고 계수 크기를 요약하려고 현재 방식을 쓴다.

M은 10으로 나누어떨어져야 한다. 그렇지 않으면 block_power_and_statistics가 ValueError를 낸다. 그림의 축은 원래 모드 번호 0~M이며 각 픽셀은 원소 하나가 아니라 10×10 구간의 평균이다. 카탈로그 label 순서가 축 순서의 기준이다.

13.2 두 branch가 같은 색 범위를 쓴다#

두 블록 그림 중 더 큰 최대값을 공통 colorbar 상한으로 쓴다. 하한은 0, 색상은 inferno, 크기는 선형 척도다. branch마다 최대값을 1로 정규화하지 않으므로 계수 크기의 차이를 직접 볼 수 있다. 반대로 일부 큰 값이 상한을 결정하면 작은 대각 구조는 눈에 잘 안 보일 수 있다.

이 표시는 로그 척도가 아니다. 모드 번호별 물리량을 정렬해서 새 대각선을 만들지도 않는다. mode_count에서 일곱 개 정도의 눈금을 만들며, title에는 현재 DATA.name과 학습 관측 수를 쓴다.

13.3 대각 비율과 branch 비교#

대각 제곱계수 비율은 블록 그림의 대각 픽셀 합이 아니라, 원래 행렬의 정확한 Tjj만 이용한다.

\[ d=\frac{\sum_j|T_{jj}|^2}{\sum_{j,k}|T_{jk}|^2}. \]

대각 블록 하나에는 진짜 대각 원소 10개와 같은 블록 안의 비대각 원소 90개가 함께 들어 있다. 따라서 그림에서 넓은 대각 띠가 보이는 것과 d가 큰 것은 관련은 있어도 같은 측정은 아니다. 전체 제곱계수 합은 100×ΣP와 원래 합이 상대오차 10⁻¹² 이내인지 확인한다.

pair_statistics는 두 블록 power 벡터 p,q에 대해 cosine=(p·q)/(||p||||q||), 평균을 뺀 Pearson 상관계수, ||p−q||/||q||를 계산한다. 마지막 분모는 twin이다. 이는 제곱계수 그림의 비교이며 원래 복소 TM의 위상 비교가 아니다.

13.4 대각 성분은 어떻게 생기는가#

이상적으로 균일하고 모드 결합이 없는 파이버에서, 입출력에 정확히 같은 정규 모드 좌표를 쓰면 각 모드는 자기 위상만 얻는다. 이 이상적 설명은 다음처럼 쓸 수 있다. 실제 프로젝트가 이 식으로 TM을 채우는 것은 아니다.

\[ a_{{\rm out},m}=t_m e^{i\beta_mL}a_{{\rm in},m},\qquad T_{mn}=t_m e^{i\beta_mL}\delta_{mn}. \]

여기서 L은 파이버 길이, βₘ은 모드 m의 전파상수, tₘ은 손실 등을 포함한 진폭 전달계수다. δₘₙ은 m=n일 때 1, 다를 때 0인 Kronecker delta다. m과 n은 각각 출력 및 입력 모드 번호다.

현재 코드의 대각 원소는 데이터로 맞춘 Tstatic에 입력 사전, 좌우 반전, 출력 카메라 압축, 출력 pseudoinverse를 곱한 결과다. 코드에는 ‘대각을 크게 하라’는 제약이나 대각 행렬을 정답으로 주입하는 단계가 없다. protocol에도 diagonal_constraint=False가 기록된다.

대각성이 약한 원인으로 실제 모드 결합, 입출력 축 및 배율 불일치, H 성분만 관측하는 중복 사전, 작은 특잇값 처리, pupil 위상 불확실성, 드리프트 잔차, 제한된 입력 NA 등을 구분할 수 있다. 그림만으로 이 중 하나를 확정할 수 없다. 특히 다른 DATA의 그림을 비교할 때는 crop, 사전 norm, rank, 공통 색상 상한도 함께 봐야 한다.

13.5 PNG와 PDF가 만들어지는 위치#

최종 대조한 plot_dataset_tm.py는 아래 반복문으로 PNG와 PDF를 모두 저장한다. PDF는 앞의 pupil 적합이나 TM 회귀 단계가 아니라 이 plotting 단계에서 만들어진다.

for extension in ('png','pdf'):
    fig.savefig(OUT / f'modal_tm_primary_twin_linear.{extension}',
                dpi=180, bbox_inches='tight')

파일은 OUT/modal_tm_primary_twin_linear.png와 OUT/modal_tm_primary_twin_linear.pdf다. 두 파일을 저장한 뒤 modal_block_power.npz와 plot_checks.json을 기록한다. 따라서 파일 날짜와 plot_checks의 source SHA256을 함께 확인하면 어느 행렬로 만든 그림인지 추적할 수 있다.

PNG만 출력하도록 나중에 바꾼다면 (‘png’,)처럼 쉼표가 있는 1원소 tuple을 사용해야 한다. (‘png’)는 문자열이라 문자 하나씩 반복하므로 정상적인 저장 반복문이 아니다. 최종 문서는 작성 중 확인된 원본의 변경 사항을 반영했으며, 설명서 작성 작업에서 프로젝트 소스를 수정하지 않았다.

14 물리적 가정과 해석의 범위#

14.1 수치 일치와 물리적 타당성#

정규방정식 잔차가 작다는 것은 작성된 행렬 방정식을 잘 풀었다는 뜻이다. primal/dual 일치는 두 식이 같은 연산을 구현했다는 뜻이다. 모드+잔차 일치는 좌표 변경 후 원래 정적 예측을 보존했다는 뜻이다. 어느 하나도 pupil이나 출력 모드 모델이 실험의 참 광학계를 정확히 나타낸다는 충분조건이 아니다.

독립 validation이라는 말도 범위별로 다르다. pupil validation은 같은 측정의 선택 패턴을 나누어 입력 강도 예측을 비교한 것이다. registration heldout은 같은 reference 영상 안의 다른 공간 블록이다. 정적 TM의 보고 오차는 학습 관측 전체에 대한 오차다. target의 새로운 복소 출력은 이 pipeline에서 평가하지 않는다.

14.2 카탈로그를 재사용할 수 있는 조건#

동일한 균일 파이버 구간의 고유모드를 정의하는 파장, 코어 지름, 굴절률 분포와 경계 조건, 모드 family 및 순서·정규화 규약이 같다면 같은 모드 카탈로그를 사용하는 것은 모델 관점에서 가능하다. 그러나 카메라와 관측 연산은 별개로 확인해야 한다. 코드의 generator_version 일치는 이 물리 조건 전부가 현재 실험과 맞는지 검사하는 기능이 아니다.

현재 코드에는 633 nm, 초점거리 4 mm, SLM pitch 12.5 μm, 코어 지름 105 μm, 출력 배율 50, 카메라 pitch 3.45 μm 등의 상수가 여러 계산에 들어 있다. 카탈로그의 값만 바꾸고 나머지 상수를 그대로 두면 내부적으로 서로 다른 광학계를 표현할 수 있다.

14.3 렌즈처럼 변형된 파이버 출사면#

출사면이 렌즈 형태이면 ‘균일한 파이버 내부의 모드가 존재하는가’와 ‘카메라 광장을 평평한 단면의 모드로 바로 분해할 수 있는가’는 서로 다른 질문이다. 균일한 구간에는 기존 모드 표현이 유용할 수 있지만, 변형된 끝단과 자유공간 전파·이미징이 출력장을 바꿀 수 있다. 출사면 전체에서 같은 균일 도파로 모드가 그대로 성립한다고 가정하기는 어렵다.

개념적으로는 아래처럼 끝단 연산자를 분리해서 생각할 수 있다. 이것은 현재 코드에 추가 구현된 식이 아니라 물리적 경계를 설명하는 도식이다.

\[ E_{\rm camera}=\mathcal P_{\rm imaging}\mathcal L_{\rm tip}\Phi a. \]

Φa는 균일 구간 모드의 중첩, Ltip은 변형된 출사면의 굴절·위상 변화 및 결합, Pimaging은 이후 전파와 카메라 이미징이다. 현재 출력 사전에는 nominal 배율과 crop, Hann, resize 모델은 들어 있지만 렌즈형 끝단의 형상·곡률·굴절을 별도로 계산하는 Ltip은 없다.

따라서 대각 성분이 약해졌다는 사실만으로 카탈로그 파일을 잘못 골랐다고 결론 내리거나, 모든 내부 모드가 사라졌다고 결론 내릴 수 없다. 정적 Fourier TM은 실제 입출력의 선형 관계를 근사할 수 있어도, 그 행렬을 기존의 평면 H 모드 사전으로 표현한 계수의 물리 해석은 추가 가정에 달린다. 이 설명서에서는 끝단 모델을 새로 추정하거나 모드 사전을 교체하지 않았다.

14.4 코드가 자동으로 판단하지 않는 사항#

reference 입력이 실제로 p2000인지, 카메라 배율 50이 유효한지, source mtime이 실제 측정 시각과 대응하는지, 두 branch 중 어느 위상이 맞는지, 선택된 모드 사전이 렌즈형 출사면의 관측장을 충분히 표현하는지를 이 프로그램이 자동 증명하지 않는다. 이 값들은 입력 규약, 모델 가정, 별도 측정의 영역이다.

15.3 완료된 출력의 재사용#

현재 prepare_outputs는 metadata가 존재한다는 이유만으로 무조건 FileExistsError를 내지 않는다. source 경로, Eout 파일의 크기·수정시각, shape, q, piston, valid, 시간, reference 옵션, 주파수 등과 저장 bundle을 비교해 같으면 재사용하고 종료한다. 다르면 이유와 –replace-existing 안내를 포함한 ValueError를 낸다.

이전 대화의 ‘Completed metadata exists’ 오류는 다른 버전의 동작이다. 현재 설명서의 기준은 이번 코드 사본이다. –replace-existing은 기존 출력을 새로 만드는 명시적 선택이며, 실패한 실행의 .partial이나 이전 metadata가 남아 있는 상황과 구분한다.

15.5 메모리와 처리량#

출력 배열 저장 크기는 대략 8·n·36864바이트, 정적 T 하나는 8·36864·p바이트다. original 모드 행렬 한 개는 8M²바이트다. 예를 들어 M=6000인 가상 경우 한 행렬만 약 288 MB이며 두 branch와 중간 complex128 배열을 합치면 더 커진다. 이 숫자는 메모리 계산 예이고 현재 측정의 M을 보고한 값이 아니다.

큰 배열을 mmap으로 읽는다고 모든 GPU 계산이 저메모리인 것은 아니다. fit_static은 출력 Y 전체와 특징, Gram 등을 GPU에 올리고, modal은 여러 큰 사전과 변환 행렬을 만든다. 출력 FFT batch를 8에서 1로 줄이는 옵션은 output 전처리의 CPU 작업량을 줄이며 build의 GPU 메모리 부족을 직접 해결하지 않는다.

configure_runtime은 OUT 아래 .cupy_cache, .cuda_cache, .matplotlib, .tmp를 만들고 해당 환경변수와 tempfile 경로를 설정한다. save_gpu는 GPU 값을 CPU로 옮긴 뒤 복소 배열은 complex64, 실수 배열은 float64로 저장한다. host는 CPU/GPU 값을 공통 NumPy 쪽으로 가져오는 편의 함수다.

먼저 source와 reference-pattern이 맞는지 본다. 이어 입력 전처리 오차와 clipping, pupil validation 손실, reference 이동 및 이웃 overlap을 읽는다. 그다음 static 학습 오차와 출력 주파수 보존율을 보고, modal rank·절단량·표현 비율을 확인한다. 마지막으로 original 모드 그림과 대각 비율을 해석한다.

대각선 유무부터 판단하면 앞단의 좌표나 정규화 문제와 실제 모드 결합을 구분하기 어렵다. 계산 흐름의 앞에서 뒤로 진단하면 어떤 단계의 가정이 결과에 영향을 주는지 추적할 수 있다.

18.2 학습 점검 문제#

문제 1. 입력 광장 두 개의 강도가 같으면 위상도 같은가. 답: 아니다. E와 E*를 비롯해 서로 다른 위상이 같은 |E|²를 만들 수 있다. 이 코드에서는 pupil의 공간 반전과 켤레가 twin 모호성을 만든다.

문제 2. outputs의 행 nscan+7은 무엇인가. 답: reference 배열의 0 기반 인덱스 7이다. 파일 이름은 drift_p0070_f0.bmp 규칙과 대응한다.

문제 3. rᵢ=60, rₒ=1000인 가상 경우 observable 행렬 크기는 무엇인가. 답: 1000×60이다. 원래 모드 개수가 M이면 original 행렬은 여전히 M×M이다. 이는 예시이며 현재 측정의 rank를 뜻하지 않는다.

문제 4. 모드+잔차가 정적 TM과 정확히 일치하면 모드 모델이 참인가. 답: 아니다. 잔차를 정의할 때 원래 행렬과 모드 표현의 차이를 남겼으므로 합의 일치는 구현 검증이다. 잔차의 크기와 입력별 출력 설명력을 별도로 확인해야 한다.

문제 5. 대각 그림을 진하게 만드는 것이 코드 최적화의 목표인가. 답: 아니다. pupil은 강도 손실, 출력 정렬은 overlap, 정적 TM은 ridge 손실을 최적화한다. 모드 대각 제약은 없다.
